# M8 security review — Linux checkpoint, 2026-11-03

This is a source and executable-test checkpoint, not a completed cross-platform security assessment. The review covers OpenKraken's renderer/main boundary, repository URI dispatcher, native helper capabilities, diagnostic content handling and signed AppImage update path. Provider authentication/authorization, all repository mutation paths, terminal integration, native Windows/macOS behavior and production release operations require separate coverage.

Repository opening does not sandbox native Git, configured hooks, external tools or the user's terminal. Those execute as the user by design. Private files and integrity checks resist accidental corruption and unsafe storage; they do not establish protection from arbitrary code already running as the same account.

## Dependency finding and remediation

The initial full pnpm audit reported two moderate development advisories: [minimatch pattern amplification](https://github.com/advisories/GHSA-g3hv-75wg-m249) and [glob cancellation bypass](https://github.com/advisories/GHSA-3g3m-2fjr-6pw4). Modern dependency branches now resolve minimatch 11.0.1 and glob 14.0.2. [ADR 0107](../decisions/0107-build-time-glob-security-updates.md) records scope, compatibility and the remaining legacy branches. Unrelated Babel and virtualization updates introduced during resolution were removed; a subsequent frozen-lockfile install passed.

The final production audit reports zero advisories. The full development audit still exits 1 with the minimatch advisory on 3.1.5 and 5.1.9. Both inspected sources lack the optimization routine described by that advisory, but the broad affected range remains unsuppressed. No clean full-audit claim is made. Original before/after/production responses are retained in [the audit artifact](m8-dependency-audit.json); an advisory scan is time-specific and does not prove absence of vulnerabilities.

## Verification record

The update native suite passed **43 tests in seven files in 130.54 seconds** before dependency replacement. Go vet passed for `apps/askpass`. After replacement, the frozen install, typecheck/build, full ESLint/Prettier, Linux x64 packaging/fuse verification and packaged desktop smoke passed. Packaged smoke includes native Bash/PTY keyboard delivery, repository picker, askpass/editor helpers, renderer isolation and cold/resident URI consent.

The rebuilt, unsigned TEST-ONLY DEB passed payload/mode/link/fuse checks and extracted-app smoke. Deliberately mismatched archive and helper hashes were rejected before desktop launch. This is not a fresh native install/upgrade/removal lifecycle run. Both Electron update tests passed in **1.2 minutes**, including the default build's disabled feed, real HTTPS checks/downloads, automatic-check consent across restart, cancellation, rollback rejection, signature tampering and shutdown during a stalled response. Test-specific bundles were removed by their cleanup; the normal build retains no test feed or key.

The prior renderer/URI/diagnostic checkpoint passed **132 focused tests and 11 Electron tests**; its exact evidence is in [M8 progress](m8-progress.md#diagnostic-url-apostrophes-and-boundary-review). Those numbers are not included in this turn's 43-test count.

Logs for this checkpoint use `/tmp/openkraken-m8-update-security-{tests,e2e}.log` and `/tmp/openkraken-m8-security-{install,frozen-install,lint,package,package-smoke,deb,deb-verify,deb-guards}.log`. Audit responses are preserved in the linked artifact. Native Windows/macOS/ARM64 execution, production signatures/notarization, full-suite regression, large-repository performance gates and beta evidence are not established by this checkpoint.
