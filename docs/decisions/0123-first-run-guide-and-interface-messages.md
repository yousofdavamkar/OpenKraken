# 0123. Guide the first repository action in the welcome screen

A new profile opens the guide in the existing welcome screen. The local-folder choice starts selected. The other choices use the same clone dialog and initial-branch form as the toolbar. A native folder picker still controls which directory the app opens or modifies. Users can move between choices with the arrow keys, skip the guide, or use the toolbar directly. The initialize form gives focus to the branch field. Cancelling either native folder picker or closing the clone dialog returns keyboard focus to the control that launched it. The picker preserves focus if the user has moved to a different control.

The renderer records one completion flag in profile-local storage after the user skips the guide or a repository snapshot opens successfully. Cancelling a picker, encountering a Git error, or opening the clone form leaves the guide available. The welcome screen offers **Getting started** after completion. A profile upgrading from a build without the flag sees the guide on its next welcome screen. If storage is unavailable, the choices and skip button still work for the current view.

The welcome strings are bundled with the renderer. The English keys define the TypeScript contract for other catalogs. The initial second catalog is Spanish. The renderer checks the browser's language preferences in order, uses the base language for regional variants, and falls back to English if none match. A language change updates the visible messages without restarting an operation. The welcome landmark declares the selected language for assistive technology. The rest of the application retains its English document language.

Electron tests cover a Mexican Spanish launch, a change to an unsupported language, keyboard selection and skipping, replay after restart, a cancelled picker, a failed open, and successful native open, clone and initialization. The native checks compare the cloned HEAD and the requested initial branch. [M7 verification](../verification/m7-progress.md)
